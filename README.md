# Sistema de Orçamento de Aluguel de Imóveis em Python

Projeto acadêmico desenvolvido em Python para automatizar a geração de orçamentos de aluguel de imóveis.

## Sobre o projeto

A aplicação permite selecionar diferentes tipos de imóveis, como apartamentos, casas e estúdios, calcular o valor mensal do aluguel com base em suas características e adicionais, aplicar descontos e realizar o parcelamento do contrato.

O projeto também permite gerar um arquivo CSV contendo as parcelas do orçamento.

## Funcionalidades

- Cadastro e seleção de diferentes tipos de imóveis
- Cálculo do valor mensal do aluguel
- Inclusão de características e opções adicionais
- Aplicação de descontos
- Cálculo das parcelas do contrato
- Geração de arquivo CSV com as parcelas

## Conceitos utilizados

- Python
- Programação Orientada a Objetos (POO)
- Classes e herança
- Estruturas condicionais
- Lógica de programação
- Manipulação de arquivos CSV

## Objetivo acadêmico

O projeto foi desenvolvido como atividade acadêmica durante a graduação em Ciência da Computação, com o objetivo de aplicar conceitos de programação, orientação a objetos e manipulação de arquivos em uma aplicação prática.
